
# CMSC 197 NLP Mini Project

## An Experimental Study of Context-Aware Toxicity Detection in Multiplayer Game Chats

### Project Overview
This project investigates whether incorporating preceding messages from multiplayer game conversations improves toxicity detection compared to analyzing individual messages in isolation.

### Research Workflow
1. Data Preprocessing
2. Contextual Data Construction
3. TF-IDF with Logistic Regression
4. Context-Free BERT
5. Context-Aware BERT
6. Experimental Evaluation

### Project Structure
- data/: Dataset storage
- notebooks/: Jupyter notebooks
- src/: Reusable Python implementations
- tests/: Unit tests
- figures/: Visualizations
- docs/: Project documentation

### Setup
1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Place the authorized CONDA dataset files in data/raw/.

5. Run notebooks in numerical order.

### Dataset
CONDA - Contextual Dual-Annotated Dataset for in-game toxicity understanding and detection.
